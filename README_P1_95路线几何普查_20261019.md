下载两份 .py 文件并传到 `$ROOT/hv_v8/`。不必再解压原包或改其他源文件。


它锁定 95 条的 manifest 路径、SHA 和预期 Town SHA，然后按 Town 分组（最多 5 次 load_world）扫描每条 ego_route 的前 50 个点。不检测车辆的物理出生。输出 `summary.json`（全局分类）、`records.jsonl`（95 条逐记录分类）、`anomalies.jsonl`（逐异常路点的原始 road/lane/s/xyz、XODR 和精确 Driving、投影诊断）。即使中途失败，已完成的记录会留存且不标记全量完成。

## 核心对照（不要将查询缺失自动判通过）

| status | 意义 |
| --- | --- |
| `verified_xodr_and_exact` | XODR 原始锚点 + 原始坐标精确 Driving 交叉检查通过 |
| `verified_xodr_road_end_exception` | XODR 返回 None，但经过道路端点与原始位置独立验证 |
| `xodr_source_verified_exact_none` | XODR 原始锚点强一致，但精确位置查询 None；这是查询契约冲突，**不是 P1 PASS** |
| `xodr_source_verified_exact_other_lane` | XODR 可信，但 exact 查询返回另一条 lane；保持异常 |
| `xodr_source_verified_exact_geometry_conflict` | XODR 可信但另一路径的几何检查冲突 |
| `both_lookups_none` | 两个查询都缺失，不能承认坐标合法 |
| `xodr_missing_not_verified_endpoint` | XODR 缺失且未通过路端例外 |
| `xodr_source_geometry_or_identity_mismatch` | 原始 road/lane/s/xyz/yaw 与 XODR 不一致 |
| `query_exception` | CARLA API 查询异常，不能通过 |

本工具不会把 `project_to_road=True` 得到的位置写入数据，也不自动抬高 z。
